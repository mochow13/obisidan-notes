# Building Reasoning Models
### Inference-Time Scaling
The idea behind inference-times scaling is to increase computation during inference for better results. One examples is chain-of-thought (CoT) prompting where users add phrases like "think step-by-step" which encourages the model to generate reasoning steps.
### Pure Reinforcement Learning (RL)

![](https://substackcdn.com/image/fetch/$s_!_9Z-!,w_1456,c_limit,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2Fa5bb6ecc-7e46-45fe-abff-1eb02e6b0e3a_1556x1162.png)

- DeepSeek-R1-Zero was trained exclusively on RL without any SFT stage.
- It used two rewards:
	- **Accuracy reward**: LeetCode compiler to verify coding answers and a deterministic system to evaluate mathematical responses.
	- **Format reward**: LLM as judge that ensures responses follow the expected format.
This simple approach was enough for the LLM to develop basic reasoning skills! Researchers observed the famous "Aha!" moment in the model's reasoning traces.
### SFT + RL for DeepSeek-R1
- DeepSeek-R1-Zero was used to generate "cold start" SFT data
	- It's called cold start because this model was not trained using SFT itself
- DeepSeek V3 was then trained with this cold start data and another RL with the same accuracy and format rewards
	- A consistency reward was added to prevent the model from switching between languages
- After the RL stage, the most recent checkpoint of the model was used to generate 600K CoT SFT examples while an additional 200K knowledge-based SFT examples were created using the DeepSeek-V3 base model
- The total 800K generated data samples were then used for instruction fine-tuning DeepSeek V3 after which another RL round was run
	- This stage is very similar to RLHF except that the SFT data has more CoT examples
